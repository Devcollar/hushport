Install HushPort

Get the Mac app from GitHub Releases and the iPhone app from TestFlight. Pair once with a QR code, then stream over your local Wi‑Fi.

Mac

macOS 14 or later · Apple Silicon or Intel

  1. Download HushPort-0.1.0-beta.2.dmg (or the latest from Releases).
  2. Open the DMG and drag HushPort to Applications.
  3. Launch from Applications. Approve in System Settings → Privacy & Security if macOS blocks the first open.
  4. Enable Local Network for HushPort when prompted.
  5. Click Install or Update HushPort Audio and restart your Mac.
  6. Set System Settings → Sound → Output → HushPort.
  7. Pair your iPhone using the QR code in the Mac app.
Beta 2 finds your iPhone automatically on the same Wi‑Fi — you usually don’t need a manual IP address.

iPhone

iOS 17 or later · physical device required

  1. Install TestFlight from the App Store.
  2. Open the HushPort TestFlight link on your iPhone.
  3. Tap Accept → Install.
  4. Open HushPort and scan the Mac QR code to pair.
  5. Tap Start Listening when you want to receive audio.
The iOS Simulator cannot receive LAN audio. Use a real iPhone on the same Wi‑Fi as your Mac.

Daily use

1

Start Listening

Open HushPort on iPhone and tap Start Listening.

2

Stream on Mac

On Mac, tap Stream Mac audio (or send a test tone first).

3

Listen

Audio plays on your iPhone speaker or connected earphones.

Troubleshooting

iPhone not found on Mac

On iPhone, tap Stop Listening then Start Listening. On Mac, enable Local Network for HushPort in System Settings. Both devices must be on the same Wi‑Fi (not guest network).

No audio playing on iPhone

Confirm Mac sound output is HushPort. Turn up iPhone volume. Try Send test tone on Mac first.

Streaming enabled but silence on Mac

Beta 2 stops sending silent packets after ~30 seconds to save power. Mac shows Waiting for audio… but streaming stays on — audio resumes automatically when sound returns.

After changing Wi‑Fi

Tap Stop Listening → Start Listening on iPhone, then stream again from Mac.
